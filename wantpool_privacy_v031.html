WantPool Privacy Policy

Last updated: August 21, 2026

WantPool is designed so Discogs Wantlist and Marketplace data stay local to each user's browser. The shared WantPool backend receives only information a user intentionally shares for coordinating a private group order.

Local browser data

WantPool may locally store your WantPool display name, Discogs username, personal Discogs API token, Supabase configuration, optional imported Wantlist CSV, current local seller context, local scan results and local host shipping calculations.

Your Discogs API token, Discogs username, complete Wantlist, imported CSV, seller inventory, Marketplace listing IDs, Marketplace prices and item conditions are not intentionally uploaded to the WantPool shared backend.

Discogs API processing

WantPool uses the Discogs API locally to access your own Wantlist and the current seller's inventory. Catalogue artist/title information for records you intentionally choose may be shared with your WantPool group. Marketplace details remain local to the browser that requested them.

Shared WantPool data

The shared backend may store a WantPool display name, a user-created pool label, invite/session identifiers, selected catalogue artist/title information, and internal request statuses such as Requested, Added, Bought or Unavailable.

Third-party services

WantPool uses Discogs for catalogue/Marketplace API access, Supabase for private pool synchronization, and Google Chrome browser APIs for extension functionality and local storage.

No sale or unrelated use

WantPool does not sell user data and does not use it for advertising, creditworthiness, lending decisions, or unrelated purposes.

Discogs notice

This application uses Discogs’ API but is not affiliated with, sponsored or endorsed by Discogs. “Discogs” is a trademark of Zink Media, LLC.

Contact
